Features

Built for Real Signal Conditions

Designed with hands-on knowledge of Indian Railway signal hardware and field conditions.

🎯

Movable Crosshair

D-pad and touch-to-place targeting. Smallest crosshair on new touch, auto-resizes to detected signal.

🔴

HSV Color Detection

Red, green and yellow signal classification using HSV and channel-ratio analysis tuned for Indian Railways lamps.

📷

Auto Exposure Scan

Session-based EV scan finds the exposure level with the best signal-to-noise ratio and locks to it.

🔊

Voice Alerts

Announces signal color, exposure changes, signal loss and re-detection using Text-to-Speech.

🔔

Signal Change Alarm

Audible alarm when a watched red signal changes. Configurable alert system for safety monitoring.

🌙

Screen Dimming

Auto-dims display to save battery on long runs. Instant restore on touch. Pauses during help screens.
